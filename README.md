# RedRiversEdgeFitness

AI-coached training app with Red, your coach. 34 programs across strength, running,
mobility, HIIT and S&C, workout logging, progress analytics, and backups.

Live: https://redriversedgefitness.netlify.app

```bash
npm install
npm test          # guards, build, and the full test suite
npm run test:e2e  # real-browser check at iPhone size
```

See [CLAUDE.md](CLAUDE.md) for structure and rules, [docs/SCHEMA.md](docs/SCHEMA.md) for data,
and [docs/BUGS.md](docs/BUGS.md) for the fix log.
